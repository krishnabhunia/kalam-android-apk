Version must be maintained in format as x.y.z
x -> major update
y -> minor update
z -> bugs or error fix

Version must be automatically managed in the GitHub as per the requirement.



Software or App must be capable to check the update once its restarted.

Also the Software App can also pull the new update from settings and install background silently.

Beta version update can be kept as optional.



The PR must be updated as beta version and from the main the full version will be downloaded.

So when beta version merges with main branch then normal release will be done.



This below instruction is only applicable for windows and macOS software app and Not for Android apks.

Update button at the top right corner must be visible only when an update has been found from GitHub and must be populated with version number "Update to vx.y.z".

Version number to be mentioned at appropriate place in the software main app window.



The below instructions is for Android.
The apk app must have a settings to check update from GitHub on everyday basis. Beta version update must be optional.
