K79 — Alarm popup screen with reachable controls (fixes v1.20)

What v1.20 shipped: a full-screen intent that opened the ordinary app screen + a Dismiss action with icon id 0 on an ongoing notification. Result: often no visible button, nothing tappable when the screen woke, and the notification could not be swiped away. Ringing for up to 5 minutes with no reachable stop. That is the defect being fixed here.

Variant A — dedicated full-screen alarm activity (recommended)

A real alarm screen, like a clock app: shows over the lock screen, turns the screen on, and the buttons are the whole point of the screen.

Snooze — how it will work (needs its own key, which is why v1.20 omitted it)

#Rule
1Snooze re-arms the SAME event at now + N minutes using dedicated slot codes 10–13 (sunrise/sunset/moonrise/moonset snooze), so the K64 fired-ledger key for the original slot is untouched
2Ledger key for a snooze becomes "code@date#seq" so repeated snoozes on the same day are each allowed, while genuine duplicate deliveries are still suppressed
3Snooze length: 5 / 10 / 15 min — chosen in the alarm sheet, default 5; snooze never survives past midnight
4Max 3 consecutive snoozes, then it stops for the day (logged) — no infinite chain

Immediate-safety rules (both variants)

#Rule
1Volume-key press silences instantly, even before the screen is read
2Ring cap 60 s (was 300 s)
3Vibration cancels with the sound, always — no orphan buzzing
4If the alarm screen cannot launch for any reason, the notification falls back to a heads-up WITH a full-size Dismiss button and the cap still applies
5Companions: STOP path unit-tested (service stop + notification cancel + vibrator cancel), snooze key vectors, cap constant test
✔ Recommended: Variant A + volume/power-key stop + 60 s cap + snooze on codes 10–13 with sequence-keyed ledger.
